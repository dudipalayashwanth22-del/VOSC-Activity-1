# 🎮 VOSC Activity-1 – Tic-Tac-Toe

## 📌 Project Description

This project is a simple and fully functional **Tic-Tac-Toe game** developed as part of **VOSC Activity-1**.

It is a two-player game where Player X and Player O take turns placing their symbols on a 3×3 board. The first player to get three symbols in a row wins the game.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

No external libraries or frameworks are used.

## ▶️ How to Run the Game

1. Download or clone this repository.
2. Open the project folder.
3. Open the `index.html` file in any web browser.

### Using VS Code

1. Open the `VOSC Activity-1` folder in VS Code.
2. Open `index.html`.
3. Right-click on the file.
4. Select **Open with Live Server** if Live Server is installed.

## 🎮 How to Play

1. Player X starts the game.
2. Click on any empty cell.
3. Player O takes the next turn.
4. Continue taking turns.
5. Get three of your symbols in a row horizontally, vertically, or diagonally to win.
6. If all nine cells are filled without a winner, the game ends in a draw.
7. Click **Restart Game** to start a new round.
8. Click **Reset Score** to reset both players' scores.
